# Safe Edit Prompt

Before making edits:

Read:
- README.md
- project-spec.md
- repo-map.md
- AGENTS.md

Project type:
Static website using HTML, CSS, and JavaScript.

Editing rules:
- Make the smallest possible change to solve the issue.
- Do not rewrite large sections unless requested.
- Preserve the current design aesthetic.
- Do not introduce frameworks.

Scope:
Only edit files relevant to the task.

CSS safety:
- Avoid breaking desktop layout while fixing mobile.
- Prefer small overrides instead of large rewrites.

Change protocol:
1. Inspect relevant files.
2. Explain the plan.
3. Make minimal changes.
4. Explain what changed and why.

Output expectations:
Always explain:
- which files were edited
- what changed
- why the change works
